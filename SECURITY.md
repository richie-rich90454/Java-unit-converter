# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Supported with security updates |
| < 1.0   | No longer supported |

Version 1.0 was released May 9, 2025. All security fixes will be back-ported to any patch releases in the 1.0.x line.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please follow these steps:

1. **Report confidentially** by creating a [GitHub Security Advisory](https://github.com/richie-rich90454/Java-unit-converter/security/advisories) or by emailing rjiang880@gmail.com.

2. **Include the following:**
   - A clear description of the vulnerability, including steps to reproduce and expected versus actual behavior.
   - The affected version(s) (for example, 1.0.0).
   - Any proof-of-concept code or test cases.

3. **Response timeline:**
   - You will receive an acknowledgment within 31 days.
   - A fix or workaround will be proposed within one month for critical issues. Non-critical issues will be scheduled according to the release cadence.

4. **After the fix:**
   - A patched version (for example, 1.0.1) will be released to the 1.0.x line.
   - A public advisory (with CVE if applicable) will be published when the fix is available.

## Security Contact

- **Preferred method:** GitHub Security Advisory mechanism (use "Report a security vulnerability" in the Security tab).
- **Alternative:** Email rjiang880@gmail.com.

Please do not open public issues for security vulnerabilities. This helps prevent attackers from exploiting unpatched problems.
